# Inpatient Data Inference - Summary of Created Files

## Overview
Created a complete inference pipeline for analyzing inpatient encounter data using the QoQ-Med-VL-7B medical vision-language model.

## Files Created

### 1. Main Inference Scripts

#### `inpatient_inference.py` (14KB)
**Purpose:** Full inference pipeline with GPU support

**Features:**
- Loads QoQ-Med-VL-7B model with flash attention
- Reads and formats inpatient encounter data
- Calculates derived metrics (length of stay)
- Maps coded values to readable labels
- Supports multiple analysis tasks
- Flexible filtering by any column
- Generates detailed analysis reports

**Key Functions:**
- `calculate_length_of_stay()` - Computes LOS from timestamps
- `format_patient_encounter()` - Creates structured clinical narratives
- `create_clinical_prompt()` - Generates task-specific prompts
- `run_inference_on_encounters()` - Main inference pipeline
- `main()` - Orchestrates the complete workflow

**Configuration:**
```python
config = {
    'num_samples': 3,
    'task': 'analysis',
    'filter_criteria': None,
    'output_file': 'inpatient_analysis_results.txt'
}
```

**Requirements:**
- NVIDIA GPU with CUDA (A100 recommended)
- 16GB+ VRAM
- All packages from requirements.txt

---

#### `prepare_inpatient_prompts.py` (9.3KB)
**Purpose:** Lightweight prompt preparation without GPU inference

**Features:**
- Formats encounter data into structured prompts
- No GPU or model loading required
- Fast data exploration and prompt testing
- Exports to text and JSON formats
- Same formatting logic as main inference script

**Use Cases:**
- Testing prompt formats before GPU inference
- Preparing batch inference datasets
- Quick data exploration
- Generating prompts for external LLMs

**Outputs:**
- `prepared_prompts_[timestamp].txt` - Human-readable
- `prepared_prompts_[timestamp].json` - Machine-readable

## Dataset Structure

**File:** `datasets/dbo.accm_inpatient.csv`

**Size:** 8,323,614 encounters × 33 columns

**Key Columns:**
- Patient: `osler_id`, `pat_enc_csn_id`
- Times: `adt_arrival_time`, `hosp_admsn_time`, `hosp_disch_time`
- Clinical: `dep_speciality`, `hospital_service`, `admission_prov`, `discharge_prov`
- Codes: `hosp_admsn_type_c`, `disch_disp_c`, `adt_pat_class_c`
- Flags: `ed_visit_yn`
- Location: `serv_area_name`, `department_id`
